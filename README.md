# Rature

Un tower defense au stylo bille. Trace des murs, rature les monstres, entoure la meute. Difficile.

```sh
npm install
npm run dev      # jouer en local
npm test         # tests de la simulation
npm run bot      # joueur automatique : réglage de la difficulté
npm run build    # version web dans dist/
```
